# StudyFlow

A responsive, student-focused study dashboard built with HTML, CSS and vanilla JavaScript.

## Features in this first version
- Responsive dashboard for desktop and mobile
- Study task planner (add, complete, delete)
- Local progress, points and achievement tracking
- Focus timer (15, 25 and 50 minute presets)
- Local browser storage (your data stays in this browser)
- No backend or paid API required

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a public repository named `studyflow`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for GitHub Pages to publish your site. The public URL will appear in the Pages section.

## Notes
- This is the first functional MVP, not the final product.
- Tasks and progress are saved in the browser's local storage. They do not sync across devices.
- The Google Fonts import is optional; if offline, the page falls back to system sans-serif fonts.
